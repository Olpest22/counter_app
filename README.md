# counter_app — сохранение состояния

На главном экране отображается число и кнопка. Каждое нажатие увеличивает число на 1.
Значение сохраняется на устройстве с помощью пакета
[shared_preferences](https://pub.dev/packages/shared_preferences), поэтому после
закрытия и повторного открытия приложения на экране показывается то же количество нажатий.

## Как это работает

1. При запуске (`initState`) приложение читает значение по ключу `counter`.
   Если значения ещё нет, используется 0.
2. При нажатии на кнопку счётчик увеличивается и сразу записывается через `setInt`.

Код находится в [`lib/main.dart`](lib/main.dart).

## Запуск

```bash
flutter create .   # при необходимости создаст папки платформ
flutter pub get
flutter run
```
